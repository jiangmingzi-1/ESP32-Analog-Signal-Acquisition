**测试日期：** 2026-11-08  
**项目版本：** V1.0

---

## 1. 项目简介

本项目基于 ESP32-WROOM-32 开发板和 B10K 电位器，搭建了一套简易模拟信号采集系统。

系统通过 ESP32 ADC 模块读取模拟输入，将采集数据通过 UART 串口发送至电脑，再使用 Python 完成数据接收、存储、统计分析和可视化。

项目主要用于学习嵌入式数据采集、ADC 模数转换、串口通信和基础信号处理。

## 3. 硬件连接

B10K 电位器采用分压器连接方式：

| B10K 引脚 | ESP32 |
|---|---|
| 一侧固定端 | GND |
| 中间滑动端 | GPIO34 |
| 另一侧固定端 | 3V3 |

电位器旋转时，中间引脚输出电压发生变化，ESP32 通过 ADC 将模拟电压转换成数字量。

注意：GPIO34 属于输入专用引脚，输入电压必须保持在芯片允许范围内。

## 4. 固件设计

### 4.1 ADC 配置

采用12位 ADC 分辨率：

\[
2^{12}=4096
\]

理论数字输出范围：

\[
0\sim4095
\]

使用 `analogSetPinAttenuation()` 设置 ADC 输入衰减等级为 ADC_11db，以扩大输入测量范围。

### 4.2 定时采样

采用 `millis()` 实现软件定时采样。

采样间隔：

\[
T=50ms
\]

理论采样频率：

\[
f=\frac{1000}{50}=20Hz
\]

通过 `next_due += INTERVAL_MS` 维护采样时间基准，并对错过的采样时刻进行处理。

本方案属于软件定时调度，并非硬件定时器保证的严格等间隔采样。

### 4.3 串口数据格式

串口波特率：115200。

数据采用 CSV 形式输出：

```text
timestamp_ms,adc_raw
30760,2555
30810,2559
30860,2559
```

其中：
- timestamp_ms：ESP32 启动后的毫秒时间戳。
- adc_raw：ADC 原始数字量。

## 5. Python 数据采集与处理

Python 通过 PySerial 连接 ESP32 串口，完成以下工作：

1. 建立串口连接。
2. 接收 ESP32 发送的数据。
3. 按逗号拆分时间戳和 ADC 数值。
4. 过滤空数据和格式异常的数据。
5. 将数据转换为整数。
6. 保存至 Python 列表。
7. 导出 CSV 文件。
8. 使用 NumPy 进行统计分析。
9. 使用 Matplotlib 绘制实验图表。

主要输出文件：

- `adc_60s.csv`
- `adc_60s_curve.png`
- `adc_distribution.png`

历史实验文件位于项目根目录下的 `data/`，本报告原有结果均保持不变。修订后的程序将新实验输出保存至 `data/runs/run_YYYYMMDD_HHMMSS/`，名称冲突时追加 `_001`、`_002` 等后缀。三个文件始终位于同一本次实验目录，控制台输出绝对路径，不再弹出保存对话框；使用独占文件创建避免覆盖。输出失败时保留已写入的部分结果。

## 8. 异常现象与问题分析

### 8.1 ADC 量程覆盖不足

早期实验中，曾出现 ADC 最小值3239、最大值4095的情况，量程覆盖率仅20.9%。

原因：实验过程中没有将电位器旋转到另一个机械限位。

处理方式：重新完成完整旋转范围测试，最终实现0～4095的数字量程覆盖。

### 8.2 Python 数据采集报错

曾出现：

```text
ValueError: min() arg is an empty sequence
```

原因：数据接收代码遗漏了数据转换与列表追加操作，导致 ADC 数据列表为空。

处理方式：增加数据格式检查、整数转换和 `append()` 保存操作。

### 8.3 NumPy 函数使用错误

曾将 `np.sum()` 错写为 `np.sin()`。

处理方式：修正函数名称，重新计算缺失数据估计值。
